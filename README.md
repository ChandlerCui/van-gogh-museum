# 梵高线上博物馆

> **Van Gogh Online Museum** —— 一座按创作生涯时间线陈列文森特·梵高代表作的线上博物馆。

### 🔗 在线访问：<https://chandlercui.github.io/van-gogh-museum/>

七个展厅、七篇序章，收录文森特·梵高 **864 件布面油画**，每件作品附年代、尺寸与馆藏信息，重点作品另配创作背景与赏析。
无后端、无数据库、无第三方运行时依赖的纯静态站点。

---

## 特色

- **时间线结构** —— 按海牙与德伦特、纽南、安特卫普、巴黎、阿尔勒、圣雷米、奥维尔七个时期划分展厅，每个展厅配一篇序章
- **作品解析** —— 22 件重点作品附完整的创作背景与画面赏析，71 件附简注，其余作品提供年代、尺寸与馆藏信息
- **三语信息** —— 中英文标题、F 编号（De la Faille）与 JH 编号（Hulsker）编目体系
- **馆藏索引** —— 覆盖梵高博物馆、克勒勒-米勒、奥赛、大都会、MoMA、英国国家美术馆等 130 余家收藏机构
- **全文检索** —— 可按作品名、馆藏地、时期即时检索
- **混合图源** —— 缩略图随站点一同分发（网格页秒开），高清大图由 Wikimedia Commons 直供，兼顾清晰度与加载速度
- **响应式** —— 桌面端与手机端分别优化，支持灯箱放大查看细节
- **轻量动效** —— 淡入与滚动揭示，并遵循 `prefers-reduced-motion` 无障碍设置

## 目录结构

```
vangogh-museum/
├── index.html              # 入口，含站点骨架与灯箱
├── css/
│   └── style.css           # 全站样式与设计变量
├── js/
│   ├── data.js             # 构建产物：window.VGM（展厅 + 作品数据）
│   └── app.js             # 路由、渲染、检索、灯箱
├── content/                # 内容层（可编辑源数据）
│   ├── manifest.json       # 展厅与作品条目（标题、年代、馆藏…）
│   ├── images.json         # 每件作品的图像来源
│   ├── interp.json         # 创作背景与赏析文本
│   └── local-images.json   # 本地化图像清单（构建生成）
├── assets/img/             # 本地缩略图 *-t.jpg；另存 7 张高清图（6 件大都会作品 + 首页首屏《星月夜》）
└── tools/
    ├── build.js            # content/* → js/data.js
    └── fetch-images.js     # 下载图像到 assets/img/
```

## 本地运行

站点为纯静态，**双击 `index.html` 即可打开**。由于使用了 hash 路由（`#/period/5`、`#/work/…`），相对路径不依赖服务器，直接打开也能正常浏览。

推荐起一个本地服务器（手机同局域网也可访问）：

```bash
cd vangogh-museum
python -m http.server 8000
# 电脑打开 http://127.0.0.1:8000/
# 手机打开 http://<本机局域网IP>:8000/
```

## 数据与构建

内容与展示分离：所有文案与条目都放在 `content/` 下，构建脚本把它们编译成前端唯一的数据源 `js/data.js`。

```bash
node tools/build.js          # content/*.json  →  js/data.js
node tools/fetch-images.js   # 下载图像 → assets/img/ + content/local-images.json
```

- `build.js` 采用**缩略图本地 + 高清图远端**策略：`content/local-images.json` 里的缩略图随站点分发；作品页、灯箱所需的大图由 Wikimedia Commons 的 `thumb.php` 直供，按展示位反推尺寸（首页首屏 ≈960、作品页 ≈1280、灯箱 ≈1920），且只取 Commons 的**常见缩略图尺寸**（非该白名单的宽度会返回 400）。仓库因此只需保存缩略图，音量由 74 MB 降至 12 MB。
- 如需重新把全部图像本地化（例如要完全离线），运行 `node tools/fetch-images.js`，它会补回 `assets/img/*-d.jpg` 并把 `local-images.json` 的 `detail`/`zoom` 指向本地文件。
- 作品 `id` 是 `images.json` / `interp.json` 的键，**不可随意变更**，否则会丢失对应的图像与文本关联。

- **作品图像**：Wikimedia Commons（公有领域）与纽约大都会艺术博物馆开放获取项目（CC0）。梵高原作已进入公有领域。
- **编目体系**：De la Faille（F 编号）与 Hulsker（JH 编号）。
- **文本内容**：本站原创整理。
- **免责说明**：作品年代与馆藏信息以各收藏机构官方数据为准，本站内容仅作欣赏与学习之用。
- 本站为**非商业性教育项目**，不对图像主张任何权利。

## 部署

本站为纯静态站点（无构建依赖、无后端服务），可直接部署到 GitHub Pages：

1. 进入仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选择 `main`，目录选择 `/ (root)`
4. 点击 **Save**，等待 1–2 分钟完成首次构建

访问地址形如 `https://<用户名>.github.io/van-gogh-museum/`。

站点使用相对路径与 hash 路由，部署在 `/van-gogh-museum/` 子目录下无需任何额外配置。
